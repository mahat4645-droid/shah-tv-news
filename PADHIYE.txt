इस फ़ोल्डर में सिर्फ़ वही 24 फ़ाइलें हैं जो आपकी लाइव साइट से अलग हैं।
खबरें, सेटिंग्स, लोगो और विज्ञापन वाली फ़ाइलें जान-बूझकर नहीं डाली गईं —
उन्हें छूना नहीं है।


───────────────────────────────────────────────────────────
भाग 1 — साधारण फ़ाइलें  (22 फ़ाइलें, आसान तरीका)
───────────────────────────────────────────────────────────
GitHub पर repo खोलिए → Add file → Upload files

फिर इस फ़ोल्डर से ये चारों चीज़ें एक साथ खींचकर (drag) छोड़ दीजिए:

      package.json
      public   फ़ोल्डर
      scripts  फ़ोल्डर
      src      फ़ोल्डर

नीचे Commit changes दबा दीजिए। फ़ोल्डर अपने आप सही जगह बैठ जाते हैं।

⚠️ .github वाला फ़ोल्डर इस तरह अपलोड नहीं होगा — GitHub का अपलोडर
   डॉट से शुरू होने वाले फ़ोल्डर चुपचाप छोड़ देता है। उसके लिए भाग 2।


───────────────────────────────────────────────────────────
भाग 2 — .github/workflows  (हाथ से बनानी होंगी, चाहें तो बाद में)
───────────────────────────────────────────────────────────
ये दोनों ज़रूरी नहीं हैं — साइट इनके बिना भी चलेगी। जब चाहें तब करें।

(क) deploy.yml — Cloudflare की बिल्ड-सीमा से बचने के लिए
    GitHub → Add file → Create new file → नाम में पूरा पता लिखिए:
         .github/workflows/deploy.yml
    (दो डॉट-स्लैश अपने-आप फ़ोल्डर बना देंगे)
    फिर इस फ़ोल्डर की deploy.yml खोलकर पूरा टेक्स्ट कॉपी-पेस्ट कीजिए।

    इसके बाद दो काम ज़रूरी हैं, वरना हर बार लाल निशान आएगा:
      1. Settings → Secrets and variables → Actions → New secret
             CLOUDFLARE_API_TOKEN    (Pages: Edit वाला टोकन)
             CLOUDFLARE_ACCOUNT_ID   (Cloudflare डैशबोर्ड से)
      2. Cloudflare → Workers & Pages → shah-tv-news → Settings →
         Builds & deployments → automatic production deployments बंद कर दें
         (वरना दो बार deploy होगा)

    अगर अभी ये दो काम नहीं करने हैं तो deploy.yml मत डालिए —
    साइट पहले की तरह Cloudflare की अपनी बिल्ड से बनती रहेगी।

(ख) notify-new-story.yml — फ़ोन पर नोटिफिकेशन भेजने के लिए
    शाह टीवी का अभी कोई मोबाइल ऐप नहीं है, इसलिए यह अभी छोड़ दीजिए।
    ऐप बनने पर इसे डालेंगे।
